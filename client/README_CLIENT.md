# Frontend only

This folder is the complete current local demo frontend and can replace the existing `CodeRed-/client/` folder **after backing it up**.

Run: `npm install` then `npm run dev` from this `client/` folder.

Contents: complete Lobby, fixed Mission workstation sprites, editable Monaco IDE, local test simulation, chat and Ready UI.

It does **not** require the server to display the local demo. No Gemini key is included.
